# Twists


Give your games a Twist, if that is speedruns, "manhunt", or whatever you play.

## Features:

### Worldless
Minecraft.. but the world around you resets every 5 minutes.

The following steps allow you to start a worldless minigame

`/minigame create twists:worldless` to create a new minigame

`/minigame join twists:worldless @a` to put all players into the minigame
confiure the reset time with a preset: `/minigame settings twists:worldless world_reset_time set from option 10_min`
confiure the reset time with a value, in ticks: `/minigame settings twists:worldless world_reset_time set from value 12000`
`/minigame start twists:worldless` to start the minigame




`/twists worldless time setdefault 6000` - Set the time per world; defaults to 6000 ticks or 5 minutes

`/twists worldless start` - Start the "minigame", once started portal linking is through the temporary worlds.

`/twists worldless pause` - If for any reason you need to pause the run without freezing the server with `tick freeze`
<br> 
*Note: this will not kick players back to the overworld.*
